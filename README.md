# Лабораторна робота №4  
## Робочий проект програмної системи «Готель»

## Тема роботи

Робочий проект.

## Мета роботи

Набути навичок з розробки робочого проекту програмного забезпечення.

## Програмна система

**Програмна система «Готель»** — це навчальний вебзастосунок для пошуку номерів, перегляду статистики готелю, створення бронювань, збереження даних клієнтів та контролю стану номерів.

Система реалізована як клієнтський вебзастосунок з використанням HTML, CSS та JavaScript. Дані зберігаються у LocalStorage браузера.

---

# 4. Робочий проект

Робочий проект програмної системи «Готель» містить опис вхідних і вихідних даних, розробку інтерфейсу користувача, кодування програмного забезпечення та результати тестування.

У межах роботи було виконано:

- опис вхідних даних;
- опис вихідних даних;
- розробку інтерфейсу користувача;
- реалізацію програмної системи;
- тестування методом чорного ящика;
- тестування методом білого ящика.

---

## 4.1 Опис вхідних даних

Вхідними даними програмної системи є інформація, яку вводить користувач під час пошуку номера або створення бронювання.

Основні вхідні дані:

| Дані | Опис |
|---|---|
| Ім’я клієнта | ПІБ або ім’я користувача, який створює бронювання |
| Номер телефону | Контактний номер клієнта |
| Email | Електронна адреса клієнта |
| Номер кімнати | Номер готельного номера, який бронюється |
| Дата заїзду | Дата початку проживання |
| Дата виїзду | Дата завершення проживання |
| Тип номера | Дані для пошуку номера за типом |
| Статус номера | Дані для фільтрації номерів за станом |

---

## 4.2 Опис вихідних даних

Вихідними даними є інформація, яку система відображає користувачу після обробки введених даних.

Основні вихідні дані:

| Дані | Опис |
|---|---|
| Статистика готелю | Кількість усіх, вільних, заброньованих і зайнятих номерів |
| Список номерів | Перелік номерів з типом, ціною та статусом |
| Результати пошуку | Відфільтрований список номерів |
| Список бронювань | Дані створених бронювань |
| Повідомлення перевірки форми | Повідомлення про незаповнені обов’язкові поля |
| Дані LocalStorage | Збережені дані номерів і бронювань |

---

## 4.3 Розробка інтерфейсу користувача

Інтерфейс програмної системи «Готель» складається з таких основних блоків:

- заголовок системи;
- статистика готелю;
- пошук номерів;
- список номерів;
- форма бронювання;
- список створених бронювань.

## 4.4 Кодування програмного забезпечення

Програмна система реалізована за допомогою трьох основних файлів:

| Файл | Призначення |
|---|---|
| `system-hotel/index.html` | Описує структуру сторінки та основні елементи інтерфейсу |
| `system-hotel/style.css` | Визначає оформлення сторінки, блоків, карток номерів і форми |
| `system-hotel/script.js` | Реалізує логіку роботи системи, пошук, бронювання, оновлення статистики та роботу з LocalStorage |

Повний код програмної системи розміщено у папці:

```text
system-hotel/
```

## Висновок

Під час виконання лабораторної роботи було розроблено робочий проект програмної системи «Готель». Було описано вхідні та вихідні дані, реалізовано інтерфейс користувача, додано файли програмного забезпечення та проведено тестування системи.

Тестування методом чорного ящика підтвердило коректну роботу основних функцій з точки зору користувача. Тестування методом білого ящика показало, що JavaScript-код виконується без помилок, а дані системи зберігаються у LocalStorage браузера.

Програмна система «Готель» відповідає вимогам робочого проекту та може використовуватися як навчальний прототип системи бронювання номерів.
